# 故障排查 (Troubleshooting)

## 启动失败

### 报 `VCRUNTIME140.dll` / `MSVCP140.dll` 缺失
**原因**：缺少 VC++ 运行库。
**解决**：安装 [VC++ 2015-2022 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

### 双击无反应 / 闪退
1. 以**管理员身份**运行 `scripts\start.bat`。
2. 运行 `scripts\check_env.bat` 检查环境。
3. 检查 Windows 版本是否 ≥ 10 1809。

## 授权失败

### `[auth] clock_skew response had invalid server_time`
**原因**：系统时间与服务器偏差过大。
**解决**：校准系统时间（开启"自动设置时间"）。

### 启动时卡在授权 / 提示未授权
**原因**：程序需联网完成授权校验。
**解决**：确认网络连接正常，防火墙/杀软未拦截程序联网。

## 自瞄不生效

### ESP 覆盖层有显示，但鼠标不动
**原因**：注入通道不可用。
**排查**：
1. 确认已安装对应鼠标驱动（罗技 G HUB / 雷蛇 Synapse）或已连接硬件盒。
2. 检查 `config.json` 中 `input_channel` 设置，尝试改为具体通道（如 `GHUB`）。
3. 以管理员权限运行。

### 完全无覆盖层、无自瞄
**原因**：屏幕采集失败或覆盖层未启用。
**排查**：
1. 检查 `overlay_enabled` 是否为 `true`。
2. 关闭全屏独占模式，改为**无边框窗口/全屏窗口化**（DXGI 桌面复制不支持独占全屏）。
3. 确认 `capture_mode` 为 `dxgi`。

## 检测不到目标 / 自瞄抖动

- 调高 `confidence_threshold` 减少误检。
- 调低 `smooth` 值降低延迟（或调高增加平滑度）。
- 确认 `aim_fov` 设置合理（过大易锁错目标）。
- 确认游戏画质/亮度足够，模型能稳定识别。

## 杀毒软件误报

外挂涉及驱动注入与签名校验，**极易被杀软/Defender 误报为恶意软件**。

- 使用前建议在虚拟机或隔离环境验证文件哈希（见 README）。
- 若确认来源可信，可将 `Au.exe` 加入杀软白名单。
- **切勿运行来路不明的同类程序**，务必核对 SHA256 与官方发布一致。

## 其它

- **游戏更新后失效**：游戏反作弊更新可能导致外挂失效，需等待对应更新。
- **账号封禁风险**：使用外挂违反游戏条款，可能导致封号，请自行承担风险。
